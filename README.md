# MDTV Overlay

Petite appli Windows qui affiche un build Heroes of the Storm (page https://mdtv-hots.pages.dev/#/en-jeu)
par-dessus le jeu, dans une fenêtre transparente. Rien n'est injecté dans le jeu.

1. Installe l'overlay et ouvre-le : la fenêtre de réglage s'affiche. « Se connecter avec Discord » ouvre ton navigateur
   habituel (là où tu es déjà connecté à Discord) ; valide, puis accepte d'ouvrir MDTV Overlay.
2. Choisis ton héros, un build (titre + auteur), puis **Enregistrer**.
3. Dans HotS, règle l'affichage sur « Plein écran (fenêtré) ». L'overlay détecte le jeu tout seul
   (sinon il affiche « En attente : jeu non lancé »).
4. En partie, **F5** affiche / cache le build. **Ctrl+Maj+D** : déplacer le panneau, puis Ctrl+Maj+D pour le fixer.

Pour quitter : clic droit sur l'icône losange à côté de l'horloge → Quitter.

Windows peut afficher « application non reconnue » : *Informations complémentaires* → *Exécuter quand même*.

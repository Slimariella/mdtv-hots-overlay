# MDTV Overlay

Petite appli Windows qui affiche un build Heroes of the Storm (page https://mdtv-hots.pages.dev/#/en-jeu)
par-dessus le jeu, dans une fenêtre transparente. Rien n'est injecté dans le jeu.

1. Installe l'overlay, puis connecte-toi avec Discord (la fenêtre s'ouvre déverrouillée la première fois).
2. Dans HotS, règle l'affichage sur « Plein écran (fenêtré) ».
3. **Ctrl+Maj+B** : afficher / cacher. **Ctrl+Maj+D** : déverrouiller (déplacer, changer de build) / verrouiller (les clics traversent).

Pour quitter : clic droit sur l'icône losange à côté de l'horloge → Quitter.

Windows peut afficher « application non reconnue » : *Informations complémentaires* → *Exécuter quand même*.
